
# BitSec DevOps Deployment Project

## Project Overview

BitSec is a practical DevOps project demonstrating
how to build, deploy and publish a web application
using local infrastructure and free services.

## Technologies

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Ubuntu 24.04
- VirtualBox
- Nginx
- Cloudflare Tunnel

## Architecture

Application Code → GitHub → Ubuntu Server →
Nginx → Cloudflare Tunnel → Live Web Application

## Hosting

The application will be hosted on a local Ubuntu
server running inside VirtualBox.

## Project Goal

Deploy a publicly accessible web application
without using a paid cloud subscription.
